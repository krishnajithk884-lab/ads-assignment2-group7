# ADS Assignment 2 – Question 7 (Group 7)
## Song-ID Hash Table (Division Method) vs Linear Search

A music application stores song IDs `105, 210, 315, 420, 525, 630, 735, 840`.
This project implements a hash table with the **Division Method** `h(k) = k mod m`,
resolves collisions with **linear probing**, and compares search cost against **linear search**.
